# Термінологія, що походить зі стандартів

Технічні терміни, термінологія, символи та відповідні описи, наведені в цій інформації або ті, що з’являються у чи на самих виробах, зазвичай походять із термінів чи визначень міжнародних стандартів.

У сфері функціональної безпеки систем, приводів та загальної автоматизації це може включати, але не обмежуватися такими термінами, як: безпека (safety), функція безпеки (safety function), безпечний стан (safe state), відмова (fault), скидання відмови (fault reset), несправність (malfunction), збій (failure), помилка (error), повідомлення про помилку (error message), небезпечний (dangerous) тощо.

Серед іншого, ці стандарти включають:

| Стандарт         | Опис                                                         |
| ---------------- | ------------------------------------------------------------ |
| IEC 61131-2:2007 | Програмовані контролери (Programmable controllers), частина 2: Вимоги до обладнання та випробування. |
| ISO 13849-1:2023 | Безпечність машин (Safety of machinery): Частини систем керування, пов’язані з безпекою (Safety related parts of control systems). Загальні принципи проєктування (General principles for design). |
| EN 61496-1:2013  | Безпечність машин: Електрочутливі захисні пристрої (Electro-sensitive protective equipment). Частина 1: Загальні вимоги та випробування. |
| ISO 12100:2010   | Безпечність машин – Загальні принципи проєктування (General principles for design) – Оцінка ризиків та зниження ризиків (Risk assessment and risk reduction). |
| EN 60204-1:2006  | Безпечність машин – Електрообладнання машин (Electrical equipment of machines) – Частина 1: Загальні вимоги. |
| ISO 14119:2013   | Безпечність машин – Блокувальні пристрої, пов’язані з огородженнями (Interlocking devices associated with guards) – Принципи проєктування та вибору. |
| ISO 13850:2015   | Безпечність машин – Аварійна зупинка (Emergency stop) – Принципи проєктування. |
| IEC 62061:2021   | Безпечність машин – Функціональна безпека (Functional safety) електричних, електронних та програмованих систем керування, пов’язаних з безпекою. |
| IEC 61508-1:2010 | Функціональна безпека (Functional safety) електричних/електронних/програмованих електронних систем, пов’язаних з безпекою: Загальні вимоги. |
| IEC 61508-2:2010 | Функціональна безпека електричних/електронних/програмованих електронних систем, пов’язаних з безпекою: Вимоги до електричних/електронних/програмованих електронних систем, пов’язаних з безпекою. |
| IEC 61508-3:2010 | Функціональна безпека електричних/електронних/програмованих електронних систем, пов’язаних з безпекою: Вимоги до програмного забезпечення (Software requirements). |
| IEC 61784-3:2021 | Промислові комунікаційні мережі (Industrial communication networks) – Профілі – Частина 3: Функціональна безпека (Functional safety) польових шин (fieldbuses) – Загальні правила та визначення профілів. |
| 2006/42/EC       | Директива з безпечності машин (Machinery Directive).         |
| 2014/30/EU       | Директива з електромагнітної сумісності (Electromagnetic Compatibility Directive). |
| 2014/35/EU       | Директива з низької напруги (Low Voltage Directive).         |

Крім того, терміни, використані в наведеній інформації, можуть частково походити з інших стандартів, таких як:

| Стандарт        | Опис                                                         |
| --------------- | ------------------------------------------------------------ |
| IEC 60034 серія | Обертові електричні машини (Rotating electrical machines).   |
| IEC 61800 серія | Системи електроприводів із регульованою швидкістю (Adjustable speed electrical power drive systems). |
| IEC 61158 серія | Цифрові системи передавання даних для вимірювання та керування (Digital data communications for measurement and control) – Польова шина (Fieldbus) для використання в промислових системах керування. |

Нарешті, термін зона роботи (zone of operation) може застосовуватись у поєднанні з описом конкретних небезпек і визначається так само, як небезпечна зона (hazard zone, danger zone) у Директиві з безпечності машин (2006/42/EC) та ISO 12100:2010.

Примітка: зазначені вище стандарти можуть застосовуватися або не застосовуватися до конкретних продуктів, наведених у цій документації. Для отримання більш детальної інформації щодо окремих стандартів, які застосовуються до описаних тут продуктів, див. таблиці характеристик для цих продуктів.
