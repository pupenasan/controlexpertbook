# Security Editor

Запустіть і використовуйте інструмент Security Editor, щоб керувати доступом до різних функцій EcoStruxure Control Expert та пов’язаного програмного забезпечення керування завантаженням. Інструмент інсталюється автоматично як частина EcoStruxure Control Expert.

EcoStruxure Control Expert Classic працює без додаткового налаштування Security Editor. Перед тим як отримати доступ до його функцій і можливостей, у Security Editor потрібно налаштувати щонайменше одного користувача Topology Manager. 

Під час інсталяції та налаштування інструмента Security Editor автоматично створюється база даних безпеки з одним адміністративним користувачем (`SecurityAdmin`). База даних містить означення користувачів, профілі користувачів і права доступу:

Захищений доступ до EcoStruxure Control Expert і програмного забезпечення керування завантаженням є необов’язковим. У EcoStruxure Control Expert параметр Security для захищеного доступу за замовчуванням вимкнено (`OFF`).

Доступ до EcoStruxure Control Expert застосовується до термінала, на якому встановлене програмне забезпечення (а не проєкт). Сам проєкт має власну систему захисту. Файл журналу може містити хронологічний запис різних операцій, виконаних користувачами, які мають доступ до програмного забезпечення.

Користувач `SecurityAdmin` зарезервований для адміністратора інструмента Security Editor, у попередніх версіях (до 15.3) це був `Supervisor` .  Після інсталяції EcoStruxure Control Expert на робочій станції лише цей попередньо означений користувач може запускати Security Editor та редагувати конфігурацію безпеки після автентифікації. Під час першого запуску інструмента Security Editor вам буде запропоновано створити пароль для користувача SecurityAdmin. Пароль можна змінити на вкладці `User Information`. Користувач SecurityAdmin має унікальний профіль у Security Editor. Лише цей користувач має адміністративні права на керування базою даних безпеки та означення списку імен користувачів і їхніх відповідних прав доступу до програмного забезпечення.

Користувач SecurityAdmin може виконувати такі дії:

- створювати або змінювати список користувачів
- створювати або змінювати профілі користувачів
- вимикати одного чи кількох користувачів
- змінювати правила доступу до програмного забезпечення
- змінювати пароль користувача SecurityAdmin
- скидати паролі користувачів
- налаштовувати механізм автентифікації для локальної або централізованої бази даних користувачів і їхніх прав доступу
- створювати, використовувати й керувати сертифікатами та формувати список сертифікатів для автентифікації довірених комп’ютерів

Профіль користувача включає означені права доступу для користувача. Він означується назвою, необов’язковим коментарем (до 256 символів) і списком прав доступу. Security Editor надає 10 попередньо налаштованих профілів, які не можна змінювати. Для доповнення цього списку користувач SecurityAdmin може створювати власні профілі.

Security Editor містить 10 попередньо означених користувачів і 10 попередньо означених профілів, які не можна змінювати.
